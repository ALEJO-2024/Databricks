# Databricks

## 📌 Sobre el repositorio

Este repositorio reúne ejercicios, prácticas y pequeños proyectos desarrollados durante mi proceso de aprendizaje en análisis de datos.

El objetivo es fortalecer mis conocimientos en el manejo, transformación y análisis de información utilizando diferentes herramientas y técnicas.

- SQL
- Python
- Apache Spark
- PySpark
- DataFrames
- Git / GitHub
